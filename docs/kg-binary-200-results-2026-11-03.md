# 200 题 RAG/KG 对比结果（2026-11-03）

两组均完成同样的 **200/200 题**，没有排除失败题目。KG 本轮回答正确率比 Vector RAG
高 **3 个百分点（多答对 6 题）**，检索材料足够率持平。保持两个二元语义指标，没有增加评分分类。

| 指标 | Vector RAG | KG + 原文合并 |
|---|---:|---:|
| 检索材料足以回答问题 | 179/200 = 89.5% | 179/200 = 89.5% |
| 回答语义正确 | 159/200 = 79.5% | 165/200 = 82.5% |

逐题配对：检索 KG 较好 3 题、较差 3 题、相同 194 题；回答 KG 较好 9 题、较差 3 题、
相同 188 题。因此本轮观察到回答增益，没有观察到总体检索充分性增益。

## 为什么之前题目总数不同

前轮计划都是 23 题，KG 的两次来源排序遇到连接失败，旧报告只用成功题数作分母，
导致出现 23 与 21。补跑后两组均完成 23/23，见[前轮补跑结果](kg-binary-results-2026-11-02.md)。

当前代码固定使用全部计划题数。临时网络错误最多尝试 4 次；任何题仍未完成时不发布该指标的
百分比。本轮 12 次来源排序连接失败、1 次评估阶段连接失败均重试成功，最终技术失败为 0。
有效的负面判断没有重试，也没有人工改分。

完整相同的请求会去重：本轮实际执行 397 个 reader 请求、397 个检索判断请求、276 个答案判断请求。
这是 API 请求数；两组各 200 题、每题两项判断的统计分母不变。

从已封存公开开发题库按固定哈希顺序抽样，排除前轮 23 题；不使用荷尔蒙资料。

语料约 **0.80 MB**，问题数约为前轮的 8.7 倍，文本量约为前轮的 2 倍。这是段落级抽样库，
不是四个数据集的全量知识库。全部段落共同参与检索，包含原数据集给出的干扰段落。
原始问题与参考答案保留；单段上下文题增加原段落标题以保留问题范围，未加入答案。

- 构图、来源排序、回答：`qwen3.6-35b-a3b`；两组统一裁判：`qwen3.5-397b-a17b`。
- 所有模型通过 Alibaba API 调用；共用 `text-embedding-v4`、1024 维 embedding 排名。
- 两组相同来源排序器、reader 和预算：最多 50 个候选，最终最多 12 个原文、14,000 字符。
- Vector RAG 使用向量召回；KG 将向量与图检索得到的原文合并后排序。reader 只读取原文。
- 每项一次语义判断，只有正确/错误；不要求 exact match，不执行二次复核或旧校准流程。

完整两个 prompt 及指标定义见[固定评估协议](kg-quality-evaluation.md)。

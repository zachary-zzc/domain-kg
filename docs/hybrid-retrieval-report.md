# 本地 4B 双路检索试验：五次尝试后停止

日期：2026-10-19。**测试完成；完整证据引用标准未通过，已停止继续迭代。**

最终探索性对照中，增加轻量检索图后，答案匹配由 8/10 提升到 10/10，完整证据
召回由 7/9 提升到 9/9；但两道多跳题漏引中间证据，严格的“答对且引用完整”仍为
8/10。再加入复核后的事实关系，没有观察到额外收益。结果支持进一步验证原文检索
加轻量图的方向，不能作为真实 KG 抽取、临床质量或生产发布验收。

## 输入、模型和对照

- 16 个片段：已缓存公开 NHS PDF 中的 8 个片段，以及 8 个明确标记的合成片段。
- 10 道冻结题：2 道已知开发题、3 道新公开文档题、4 道合成关联题、1 道无答案题。
  合成关联题含两道三段证据链、一道两段关联题和一道直接事实题。
- 参考答案和关系复核均由本助手编写，不是独立医学专家或人工团队标注。新文档题
  来自同一份已阅读过的 PDF；部分未被提问的材料片段从句子中间开始，不能据此
  评价模型在完整医学语料上的抽取质量。
- 回答与抽取：本地 **Qwen3-4B Q4_K_M**，关闭 thinking，temperature 0、seed 19。
- 共用 embedding：Qwen3-Embedding-0.6B Q8_0，1024 维。为满足现有内存上限，
  全文按不超过 24 个实际 token 的窗口完整覆盖，再按 UTF-8 字节数加权池化、归一化。
  三组使用完全相同的向量。这个短窗口底座不能代表未分窗的强向量基线。
- 三组均限制最多 3 个完整原文片段、合计 1,800 字符，图扩展最多两步。实际最大
  上下文为 1,431 字符；回答上下文没有图摘要、关系描述或参考答案。

| 组别 | 最终探索版的检索方式 |
| --- | --- |
| A | 原文向量余弦检索与 BM25，使用 RRF 融合 |
| B | A 的首个种子 + 原文名称/标识符连接和文档相邻连接，沿长度归一化的边最多走两步 |
| C | B + 经过原文对应检查及本助手语义复核的 4B 关系；负关系保留记录，不作为正关系扩展 |

B 的名称连接采用英语大写词与标识符启发式，排除连续大写名称中的通用前缀，限制
高频锚点并保留文档相邻关系。它不是训练过的 NER，也不是双语或同名实体消歧方案。
这些边仅为检索线索，不被当成语义事实。实现借鉴了
[LinearRAG](https://arxiv.org/html/2510.10114v2) 的原文承载关系思想和
[KG²RAG](https://aclanthology.org/2025.naacl-long.449/) 的种子扩展思路；没有复制其源码，
也不声称复现论文算法或成绩。

## 固定首轮与探索版结果

固定首轮 v4 使用较保守的词汇/结构图、三种子扩散及排名融合。A/B/C 在全部 10 题上
得到相同的 Top-3，图没有提供新增证据；三组均 7/10 答案匹配，其中包含一题实际
120 秒超时，完整正例证据为 7/9。三道新公开文档题均正确，四道合成题仅 2/4 正确。

观察首轮排序后，第五次尝试改为名称锚点和显式路径扩展。**v5 使用已观察过的题目，
属于探索性修正，不能继续称为独立 held-out 验证。** 下表仅比较 v5 内相同输入预算
下的三组。原先超时的 A 组开发题在 v5 重试一次成功；7/10 到 8/10 的这部分变化
来自重试，不应归功于图。

| 指标 | A 向量＋关键词 | B 增加轻量图 | C 再加复核关系 |
| --- | ---: | ---: | ---: |
| 完整召回全部必需片段，9 道有答案题 | 7/9 | 9/9 | 9/9 |
| 答案匹配，全部 10 题 | 8/10 | 10/10 | 10/10 |
| 答案匹配且必需引用完整，全部 10 题 | 8/10 | 8/10 | 8/10 |
| 3 道新公开文档题：答案及引用完整 | 3/3 | 3/3 | 3/3 |
| 4 道合成题：答案匹配 | 2/4 | 4/4 | 4/4 |
| 4 道合成题：答案及引用完整 | 2/4 | 2/4 | 2/4 |
| 1 道无答案题：明确拒答 | 1/1 | 1/1 | 1/1 |

这里的答案匹配是暂定标签匹配；“引用完整”检查全部必要原文片段是否同时被检索到
并被回答引用，不是通用语义蕴含或临床真实性判定。引用 ID 位于上下文中的弱校验，
与引用足以支撑完整结论的强校验分开记录。

两道三段证据题展示了主要改善与剩余问题：

- Aster：原文分别陈述项目使用 Flux-7、Flux-7 测量 Kappa、Kappa 由 Nera 产生。
  A 只找到部分证据，输出绕圈的缺失说明。B/C 找齐三段，答对 Nera，却仅引用 c11，
  没有引用连接项目和 assay 的 c09、c10。
- Boreal：原文同时否定使用 Flux-7、肯定使用 Vega-2，后者连接 Sigma 和 Luma。
  A 缺少最后一段，编造了上下文中不存在的“thyroid gland”。B/C 找齐证据后答对 Luma，
  但只引用 c14，遗漏 c12、c13。

因此，检索图已在这个受控样本上改善证据覆盖及答案匹配，完整引用仍然失败。
下一步应验证服务端证据包和消费端引用校验，不能把检索连接直接升级为事实证明，
也不能自动补引用后宣称模型已经完成了验证。

## 4B 关系抽取观察

16 个片段的调用均完成，产生 23 条候选。10 条未通过原文对应检查；剩余 13 条中，
语义复核保留 7 条、拒绝 6 条。保留项为 6 条正关系和 1 条负关系。这里没有完整的
关系金标准，因此这些数量不是关系抽取 precision/recall 或临床质量评分。

模型仍会反转被动语态：把“Marker Kappa is produced by gland Nera”写成 Kappa
produces Nera，Sigma/Luma 的对应片段也发生同样错误；医学片段还出现了未被引文
支持的主体、类别和 uses 关系。部分可定位到原文的候选仍把动词当实体，或把并列
事件推成实际使用关系。严格复核拒绝这些候选；C 组因此是稀疏、部分覆盖的图。

C 没有额外增益只说明这一小样本及这份稀疏图未带来改善，不能推断高质量事实 KG
没有价值。7 条候选的复核由本助手完成，**不能当作纯本地 4B 自动验证成功**。

## 五次记录、成本与停止

此前五次抽取迭代保持关闭。本次为用户新授权的另一项试验，单独沿用最多五次失败
的上限；准备和诊断失败也保守计入。

| 次数 | 策略与结果 |
| --- | --- |
| 1 | 继承 embedding 运行配置。首个请求后自有进程不可用，准备未完成；当次无峰值日志 |
| 2 | 精确复现并记录诊断：采样 RSS 1,307,000,832 字节，超过 1.25 GB，看门狗停止进程 |
| 3 | 计算窗口及批量降至 512，仍达到 1,428,963,328 字节并被停止；没有放宽内存上限 |
| 4 | 24-token 完整覆盖池化、4B 的 16-token prefill 微批次。完成固定三组对照，但图无增益，另有一题超时 |
| 5 | 名称锚点、边长度归一化和两步路径。证据与答案改善，但严格引用指标未改善；停止 |

缩小实际输入窗口后避免了本次观察到的 embedding 超限；底层分配路径的具体原因
尚未用分配器追踪证实，不将其写成已证明的 BLAS 缺陷。原生 RSS 上限是采样看门狗，
不是操作系统内存硬隔离。数据库的既有硬上限和配置保持不变。

所有阶段使用两 CPU 线程、单槽、无 GPU、一次一个模型。4B 上限保持 3.5 GB，
embedding 上限保持 1.25 GB，没有下载权重、安装依赖或调用外部模型 API。
五个策略均已结束；控制器实际拒绝第六次，所有自有模型 PID 退出，29500/29501

## 固定条件

- 35B 构图、来源排序和回答；统一 397B 裁判；模型均通过 Alibaba API 调用。
- 相同 `lightrag_general_v2` 提取流程、检索代码、prompt、embedding 模型及维度。
- 两组最多 50 个来源候选，最终最多 12 个原文、14,000 字符；reader 只接收原文。
- 每项一次语义判断，不用 exact match，不因评分错误而重新评判。
- 网络错误重试且保留每次记录；未完成时不缩小分母或公布不完整比例。

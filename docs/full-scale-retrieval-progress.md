## 离线检索与本次修复

两种方法共享向量 exact-cosine top50 和 BM25 top50，再通过正式 RRF 融合；图方法加入有界图遍历、图候选排序和可追溯关系路径。最多 12 个完整来源、14,000 内容字符；图路径也计入同一字符额度。读取已有向量缓存，不新增嵌入调用。

v2 的 5,000 个证据包虽通过来源和预算校验，但四组均没有两跳路径。原因是 200 个起点占满 200 个节点额度，正式遍历无法加入未检索到的桥接节点。修复后起点上限为 `max(1, max_nodes // (max_hops + 1))`，为各跳保留节点空间；零跳仍可使用全部节点额度。其他检索、构建与评审参数未改变。

## 评价规则与基线分项

不使用 exact match。允许别名、近义表达、等价单位和日期、直接算术、普通指代与有原文支持的合理短推断；问题有歧义时接受合理解释。无需找齐参考链的每个节点，也不要求匹配参考来源 ID。仍检查人物角色、关系方向、否定、时间和原文明示条件，避免把猜中答案当成有据检索。

先在不提供参考答案的条件下评价证据有用性、可答性和引用支持，再提供参考答案进行语义判定。固定 35B-A3B 读者；当前统一主裁判为启用推理的 Qwen3.8-2.4T-A95B，原 397B 非推理判定保留为敏感性结果。后者曾把“第四个女儿 → 三个姐姐”误判为证据不足，因此统一增加推理裁判，不对个别有利样本换裁判。

825 道原可答题：确认语义正确 539 题，1 题语义未判，语义正确率 539/824 = 65.41%；有据正确 521/825 = 63.15%。正确记 1、部分正确记 0.5 的分级语义分为 68.91%。证据或语义任一未判共 3 题。

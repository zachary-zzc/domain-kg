## 实现、验证与复现

新入口 [eval/kg_binary.py](../eval/kg_binary.py) 复用现有检索、来源合并、reader 和 API
记录代码；只使用两个短 prompt。答案裁判不接收引用编号或检索原文，引用错误不影响
accuracy；检索裁判只看问题与最终检索原文。完整定义和 prompt 见
[当前评估协议](kg-quality-evaluation.md)。

验证：相关单元测试 **61 passed**，Ruff 通过。测试覆盖输入隔离、每项只调用一次、
答案与检索指标相互独立、错误引用和纯文本回答仍可做语义评价，以及 API 失败的独立记录。
新结果审计确认 46 个计划记录齐全、原文未截短或改写、无重复来源、预算相同、请求/响应
模型一致、没有复用旧回答或旧评估响应。

实际请求数：46 次来源排序、43 次 reader、43 次检索判断、30 次答案判断。
相同完整请求在本轮内去重，所以调用数小于逐方法题数之和；没有二次复核。
162 次尝试中 2 次排序连接失败，其余调用及二元标签解析均成功。
提供商成功响应累计报告 567,676 tokens，未核实价格，不估算费用。

包含来源排序 API 的离线检索墙钟 p50/p95：Vector 为 0.921/1.195 秒，KG 为
0.944/4.701 秒；统计包含失败尝试，不是线上数据库或完整问答延迟。

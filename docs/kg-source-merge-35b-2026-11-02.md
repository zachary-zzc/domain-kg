# 两路原文合并与 35B 评估修正（2026-11-02）

已实现独立召回、按原文语义选择与合并，并完成固定公开开发集的 API 实验。
**这次没有证明 KG 相对相同配置的 vector RAG 带来了回答增益。** 两路确实带来不同来源，
但可比较题目的主要指标持平；未知评分仍多，不能比较不同已知分母的百分比来宣称胜负。

## 实现与边界

生产 `deep + rerank=true` 复用现有排序器：各召回分支先交错进入最多 50 项的候选池，
按出处去重并验证相同出处内容一致，再把完整原文交给所选工作模型。模型选中的来源按
语义顺序优先，未选来源按既有召回排序补齐最终预算。模型不能新建出处、修改原文或返回
越界/重复编号。最终语义顺序不再被当作另一个 RRF 投票稀释。保留跨 KG 公平性和调用前后
权限复核；fast 模式仍不调用生成式排序。

实际 API 测试发现，要求模型列全 50 个编号会误拒绝有效的 2–9 项来源选择，因此改为
验证有序子集。传给模型的候选原文完整保留；超过配置窗口明确失败，不均匀截掉每篇原文。
评估中的 API/排序协议失败记为不可用和质量未知，继续其他问题，不自动重试或填零。

构图只扩展现有通用提示，新增 `lightrag_general_v2`，关注来源支持的复合事实、明确别名
与一致端点。旧 v1 提示及缓存身份保留，新配置使用 v2；没有迁移已接受的生产知识库。
没有添加题目名称、地址正则、固定领域类型表或额外抽取流水线。

更激进的嵌套拆分提示曾在合成 smoke 中产生错误的“地址包含城市”关系，已撤回，未用于
最终图。保留的 v2 对明确别名有效，但同一 smoke 的复合地址仍是长端点；**不能声称复合
实体问题已解决**。没有用增加错误边来制造连通性。

## 固定实验条件

- 747 篇公开文档，754 个初始窗口，标题加正文共 405,461 UTF-8 bytes（约 396 KiB）。
- SQuAD 24 篇/4 题，HotpotQA 242 篇/8 题，MuSiQue 458 篇/7 题，DROP 23 篇/4 题。
- 共 23 道已审核开发题，沿用 `connected_qa_v3_reviews.json`；没有使用荷尔蒙资料。
- 构图、来源选择、回答、正确性/支持性裁判及独立复核全部使用 Alibaba
  `qwen3.6-35b-a3b` API；没有本机模型推理。
- 复用经 corpus、query、embedding model/dimensions 哈希校验的
  `text-embedding-v4`、1024 维向量排名。最早缓存因问题改写被校验拒绝，最终采用上一轮
  与当前 23 题完全一致的已验证排名。
- 两组使用同一来源选择提示、reader、裁判、温度、输出限制；最多 50 个排序候选、
  最多 12 个最终来源和 14,000 字符。排序请求窗口上界为 131,072 tokens 的保守估计。
- Vector 只做 dense 召回；KG 增加图召回，图种子仍使用现有文本匹配。两组 reader 都只
  看原文，无图摘要或图路径提示。这是离线生产检索核心实验，不是线上数据库性能测试。
- 完整核验了 46 个证据包：原文未改写、无重复出处、未截短、预算一致。两组各有一次
  排序连接失败，除此之外无有序子集协议失败。

## 评估修正

八个指标的语义定义不变，不以答案字面 exact match 评分。正确性与支持性分开；后者及
其复核不能看到参考答案。每个判断固定进行一次独立复核，不仅复核错题，也不重试到通过。
有分歧的指标保持未知，不从两个判断中选较高分。

路径诊断错误不再清空答案分数。某个组件缺失不再清空其他组件：缺少逐来源 usefulness
标签时，source precision 未知，但独立有效的需求覆盖/证据充分性保留；主张缺少 grounding
标签时，该主张支持性未知，但有效的 citation 判断保留。缺少解释 prose 不自动否定已验证
的结构化标签。省略标签不会被补成 irrelevant 或 supported。复合 grounded correctness
仍按逻辑合取计算：任一轴明确失败就为 0，不能因为另一轴未知而掩盖失败。

最后这项独立指标修正仅重新统计已保存结果。校验确认 reader、evidence、QA 和 calibration
的全部请求哈希不变，没有修改模型答案/评分，也没有追加 API 判断来追求更高分。

## 八项指标

以下均为 **35B 裁判的暂定评分**。所有方法计划分母都是 23；二值指标写“成功/已知”，
其他指标写逐题平均及已知 n。未知不会算成错误，也不会算成成功。

| 指标 | Vector RAG | KG + 原文合并 |
|---|---:|---:|
| Evidence sufficiency@12 | 22/22 = 100%；未知 1 | 21/21 = 100%；未知 2 |
| Semantic coverage@12 | 100%（n=22）；未知 1 | 100%（n=21）；未知 2 |
| Source precision@12 | 11.11%（n=9）；未知 14 | 12.96%（n=9）；未知 14 |
| Semantic correctness | 16/17 = 94.12%；未知 6 | 17/21 = 80.95%；未知 2 |
| Grounded correctness | 9/10 = 90%；未知 13 | 15/19 = 78.95%；未知 4 |
| Answer completeness | 97.06%（n=17）；未知 6 | 88.10%（n=21）；未知 2 |
| Citation support | 19/20 = 95%；未知 3 | 20/20 = 100%；未知 3 |
| Unsupported-claim rate ↓ | 0%（n=13）；未知 10 | 0%（n=16）；未知 7 |

因此“22/22 = 100%”并不表示全部 23 题检索成功。按全部计划题目的缺失值上下界，
Vector 的检索充分率为 95.65%–100%，KG 为 91.30%–100%；grounded correctness 分别为
39.13%–95.65% 和 65.22%–82.61%。这些是缺失值边界，不是置信区间。

真正逐题配对：检索充分性 20 对均持平，语义正确性 15 对均持平，grounded correctness
10 对均持平。其余配对未知。不能由上表 94.12% 与 80.95% 的不同分母推断方法差异。
各数据集、k=1/3/5/10/12、配对上下界和逐题结果保存在完整报告中。

**校准 12/12 通过，但 `semantic_ready=false`。** 来源评分遗漏、主张标签遗漏、判断分歧
以及 API 错误仍使部分指标未知。人工核查还发现两个独立裁判可能共同给出错误 citation
标签，因此上表不能作为质量改善验收证明；0% unsupported 不表示没有幻觉。

## 具体错题及剩余原因

| 问题 | 本次结果 | 原因/边界 |
|---|---|---|
| 《Cock and Bull》作者出生年份 | 两组均为 1961 | 关键原文能进入上下文，前次 1959/1927 错答消失 |
| 梵蒂冈城邦建立时间 | 两组均为 11 February 1929 | 前次 KG 缺少日期证据而拒答的问题消失 |
| Zone 5 Military Museum 所在城市的地区 | Vector: South Central Coast；KG: North Central Coast | 两组原文都有正确地区来源；KG reader 仍把 A Lưới 的属性套给 Da Nang |
| Kiev uprising 与 Battle of the Alta River 哪个更早 | 两组仍答 uprising，正确为 battle | 原文已有 “in the aftermath of”，是 reader 的关系方向/时间推理错误 |
| 特赦涉及几次 Albanian revolts | 两组仍列出 1910、1911 | 信息存在，但未直接输出数量；属于任务完成形式与语义评分边界 |
| 网球最高排名比较 | 两组均答 Ross Case | 回答事实正确，不能用引用或标签协议问题将内容自动判错 |

地区题的 correctness 标签与解释仍出现自相矛盾，独立复核把受影响的指标标为未知，
没有人工改分。先后题中 citation 裁判甚至认可了实际不能支持错误答案的引用；两遍相同
模型也不能保证判断正确。这些是剩余评估局限，不应通过为具体题目加条件修补。

## 性能、验证与记录

来源选择 API 的观测 p50 为 0.862 秒、p95 为 1.206 秒。含该调用的离线检索墙钟 p50
分别为 Vector 0.880 秒、KG 0.905 秒；不是数据库查询 SLA，也未包含用户看到最终答案的
完整耗时。46 个排序请求中 2 个连接失败。

存档的构建 API 完成记录为 1,478 次，报告输入约 185 万 tokens、输出约 143 万 tokens；
另有 4 个未确认请求。使用记录包括复用的先前尝试；问答/评估记录目录也包含未被最终
协议采用的旧请求，不能把目录总调用量解释为最后一次重算的新费用。没有核实价格，
不估算账单金额。所有旧结果和失败请求均保留，没有覆盖或伪装成新调用。

验证：相关单元回归、Ruff、严格 mypy 通过；7 个真实存储检索集成测试通过，协议放宽为
有序子集后又重跑了对应集成用例，确认优先顺序、补齐、权限和越界拒绝。
